Engineering Questions
---------------------
* Which model achieved the best accuracy? 
ResNet18 with fine-tuning (100% accuracy).

* Which model trained fastest? 
ResNet18 with the frozen feature extractor (11.05 seconds).

* Which model required the least implementation effort? 
ResNet18 with the frozen feature extractor, as it does not require unfreezing specific blocks (layer4) or applying conditional filters in the optimizer.

* Which model is most suitable for a small dataset? 
Typically, the frozen Transfer Learning model. It prevents overfitting because it has very few trainable parameters. Training a CNN from scratch with limited data usually fails or overfits heavily (as seen with the 69.4% accuracy of the SimpleCNN).

* Which model is most suitable for a real operational system? 
It depends on the risk/benefit balance, but generally ResNet18 (either frozen or fine-tuned) because it is reliable, fast to adapt, and leverages visual features robustly learned from massive datasets.

* When would you train a CNN from scratch? 
Only when you have a massive, proprietary dataset and the visual patterns are so unique that a model pretrained on standard photos (like ImageNet) would not provide a significant advantage.

* When would you use transfer learning? 
Almost always as a first option: to build rapid prototypes, when labeled data is scarce, or when computational resources are limited.

* When would you fine-tune a pretrained model? 
When the frozen model's accuracy plateaus and you need the deeper layers to adapt to the specific characteristics of your new domain (just like it happened here, jumping from 94.4% to 100%).
